# Pixel Bee

Static React/Vite landing page for the Pixel Bee design service.

The site includes the hero, process, portfolio galleries, services, pricing,
FAQ, and footer sections. It has no authentication, user accounts, payments,
admin dashboard, database, or backend service.

## Run locally

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```
